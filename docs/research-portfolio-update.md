# Research portfolio update — 9 October 2026

The portfolio introduces three independent research directions: cross-site
GeoAI, grounded scientific-presentation assessment, and adaptive human–AI
decision policies. Existing Voice and Enterprise applications remain linked
in a separate applied-project section. All five projects share navigation,
typography, editorial layout, bilingual content and restrained color identities.

## Source and status decisions

- The supplied research brief defines the questions, proposed architecture,
  hypotheses, artifact goals and publication directions.
- `KazakhstanAi/multimodal` README and `docs/research_protocol.md` establish
  the current TF-IDF/ridge baseline, prepared inputs, synthetic demo, split
  boundaries and missing full multimodal components.
- `KazakhstanAi/Human-AI-RL` README and `docs/research_protocol.md` establish
  the current simulator/LinUCB prototype, four actions, observable history,
  participant split, immediate reward and missing offline/sequential RL.
- `KazakhstanAi/central-asia-geoai` retains the initial 3–5-facility feasibility
  gate. Cross-site fusion, uncertainty diagnostics and broader benchmarking
  are proposed extensions, not implemented or validated results.
- `KazakhstanAi/vais-voice-web` README establishes the web/gateway prototype,
  inference-dependent checkpoint detection and unavailable real-mode generation.
  This is repository capability, not a claim that the remote inference stack
  is currently online.

New primary sources were checked on 9 October 2026: MulT (ACL 2019), SPECTER
(ACL 2020), LinUCB (WWW 2010, author preprint), learning to defer (ICML 2020),
and complementary team performance (CHI 2021). Each project page explains the
source's role and limits. Existing GeoAI/Voice literature keeps its original
source-check date; it is not relabelled as newly verified.

Publication venues are intended submission directions. No own paper,
participant dataset, grading validity or real-world assistance advantage
is fabricated. Planning targets (100–300 presentations; 200 × 40 decisions)
are explicit proposals, not collected sample counts or power calculations.
